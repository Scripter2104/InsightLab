# InsightLab

## Overview

InsightLab is an advanced online testing platform designed to ensure a secure and fair examination environment. It incorporates foolproof technologies to prevent tab switching and other forms of cheating, providing a reliable solution for conducting online tests.

## Project Structure

The repository is organized as follows:

- **Backend/**: Built using Django, responsible for handling authentication, test management, and security features.
- **Frontend/**: Developed using HTML, JavaScript, and Tailwind CSS for a responsive and user-friendly interface.

## Technologies Used

- **Backend**: Django
- **Frontend**: HTML, JavaScript, Tailwind CSS

## Features

- Secure online test environment
- Tab-switch detection to prevent cheating
- User authentication and test management
- Responsive UI for a seamless user experience
